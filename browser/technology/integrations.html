Technology · Integrations & API

Connect Volaxin to your ecosystem.

The unified Volaxin dataset is designed to be the operational core of your maritime IT landscape — and to talk cleanly to every enterprise, industry, and regulatory system around it.

Accounting & ERP

Bi-directional integration with SAP, Oracle, Microsoft Dynamics, and Sage for journal entries and financial consolidation. Native ISO 20022 bank payment file export.

Maritime e-commerce

ShipServ and ShipLink integration for RFQ distribution, quotation return, PO transmission, and shipment tracking. Supplier onboarding via ShipServ registry.

Classification societies

DNV MMC and Lloyd’s Register class survey planning and status exchange. Continuous survey items synchronised. Class survey certificate library maintained.

IoT & sensor ingestion

Standard-protocol sensor data ingestion (Modbus, NMEA, ISO 19848 SDS). Engine performance, tank level, cargo temperature. Feed to VOLAX PMS and VOLAX Ops.

Weather & AIS

Third-party weather-routing providers (StormGeo, Applied Weather Technology, DTN) and AIS providers (Kpler, Spire, Marine Traffic) feed VOLAX Navigate.

Open REST API

Full REST API for every module with authenticated tokens, rate limiting, and comprehensive OpenAPI documentation. Webhook subscription for event-driven integrations.
